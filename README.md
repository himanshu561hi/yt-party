# YouTube Watch Party

A synchronized video watching platform built with Node.js, Express, Socket.IO, React, and Tailwind CSS.

## Project Structure

- `backend/` - Node.js Express server with Socket.IO real-time handlers
- `frontend/` - React + Vite frontend with Tailwind CSS and Socket.IO client

## Quick Start

### 1. Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### 2. Frontend
```bash
cd frontend
npm install
cp .env.example .env
npm run dev
```

For full documentation, see [backend/README.md](./backend/README.md) and [frontend/README.md](./frontend/README.md).
